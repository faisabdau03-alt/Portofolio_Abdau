⭐ FEATURED SYSTEM 🟢 LIVE DEMO READY Vite + Supabase

Atur Produksi (Jaya Wijaya)

Sistem Manajemen Operasional, Persediaan & Payroll Manufaktur

Aplikasi single-page application (SPA) yang dirancang untuk mengelola seluruh rantai operasional produksi skala manufaktur dan bengkel kerja. Mengotomatisasi pelacakan stok bahan masuk-keluar, pencatatan mutasi kas, serta kalkulasi penggajian karyawan.

💡 MASALAH & SOLUSI YANG DIBUAT:

Pencatatan manual sering memicu stok bahan baku minus dan ketidakcocokan upah insentif karyawan per unit. Aplikasi ini menyediakan validasi stok otomatis, sinkronisasi realtime multi-perangkat via Supabase, dan ekspor laporan bulanan ke format CSV.

  • Pencatatan persediaan bahan masuk & keluar dengan sistem proteksi stok minus
  • Pencatatan mutasi kas operasional per kategori dan tanggal transaksi
  • Manajemen karyawan dengan formula gaji pokok + insentif kuantitas produksi
  • Row Level Security (RLS) Supabase untuk pembatasan hak akses data sensitif
  • Sinkronisasi data langsung antar-perangkat via Supabase Realtime
Vite JavaScript (ES6+) Supabase PostgreSQL Realtime API RLS CSS3

Mulyo Adventure 1.0

Platform Persewaan Perlengkapan Camping & Outdoor Adventure

Platform persewaan perlengkapan camping dan mendaki gunung modern. Mengadaptasi konsep rental profesional dengan fitur pemilih tanggal dan durasi sewa interaktif, modal kalkulator harga instan, dan alur checkout WhatsApp terotomatisasi.

💡 MASALAH & SOLUSI YANG DIBUAT:

Penyewa sering kebingungan menghitung total sewa untuk variasi jumlah hari dan barang. Sistem ini secara otomatis mengkalkulasi tanggal pengembalian (H+1) dan subtotal sewa secara instan serta menyimpan keranjang pesanan secara persisten di LocalStorage.

  • Interactive Booking Picker: pemilih tanggal sewa & batas pengembalian real-time
  • Katalog alat dengan live search, filter kategori, brand ternama, dan range slider harga
  • Modal detail produk dengan kalkulator sewa instan (Harga/hari × Jumlah × Durasi)
  • Keranjang belanja (Cart Drawer) interaktif persisten berbasis LocalStorage API
  • Generator konfirmasi pemesanan rapi langsung ke nomor WhatsApp admin toko
HTML5 Semantic CSS3 Modern Bootstrap 5.3 JavaScript ES6+ LocalStorage WhatsApp API
